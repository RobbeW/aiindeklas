# P40 — branded hero images

Implemented the four approved hero images in the shared `PageHero` component. The
component uses Astro's responsive `<Image>` output with reserved aspect-ratio space,
decorative empty alt text, stable `object-fit: cover` crops, and a reduced-motion
media query. Route matching is limited to `/boek`, `/contact`, `/onderwijs`, and
`/onderwijs/workshops-en-nascholingen`; images are passed explicitly by the owning
route components so prerendering cannot depend on runtime URL state. All other
PageHero consumers remain image-free.

## Image optimization

| Source | Original | Output WebP | Reduction |
|---|---:|---:|---:|
| hero_boek.jpg | 7008×4672, 7,771,656 bytes | 1600×1067, 82,446 bytes | 98.9% |
| hero_contact.jpg | 5041×3173, 2,994,286 bytes | 1600×1007, 106,158 bytes | 96.5% |
| hero_nascholingen.jpg | 1638×2048, 337,958 bytes | 1280×1600, 180,366 bytes | 46.6% |
| hero_onderwijs.jpg | 1440×1080, 150,004 bytes | 1440×1080, 147,358 bytes | 1.8% |

The WebP dimensions never exceed the source dimensions. JPEGs remain only as source
inputs and are not referenced by the component.

## Verification

- `ASTRO_TELEMETRY_DISABLED=1 astro check`: passes (0 errors; one pre-existing hint
  in `scripts/p33-browser-smoke.mjs`).
- Production `astro build`: passes; 366 static pages generated.
- `node scripts/validate-p40-heroes.mjs`: passes for all four mapped routes and
  four unrelated routes; each mapped page has exactly one eager decorative image
  with `srcset`, dimensions, and the expected optimized source, while unrelated
  pages have none.
- `node scripts/validate-responsive.mjs --project`: passes all 30 rendered
  route/viewport checks at 320, 768 and 1440px, including `/boek`; no document
  overflow or clipped controls. PageHero now uses `hyphens: auto` with normal
  word breaking and a safe `break-word` fallback, preventing arbitrary splits in
  the Boek title while retaining narrow-screen safety.
- The Boek title has a route-specific semantic `<wbr>` between `onderwijs` and
  `professionals`; the regenerated 320px output offers the readable
  `onderwijs` / `professionals` break without changing source title or metadata.
- Astro emitted responsive hashed WebP assets and dimensions for the four route
  heroes. Image dimensions are reserved by the hero aside aspect ratio to avoid
  layout shift; portrait Nascholingen uses the same stable crop treatment.
