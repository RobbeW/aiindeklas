# P39 — supplied workshop thumbnail optimization and mapping

## Outcome

The ten active workshop offers now have one exact catalogue-ID WebP thumbnail
each. The existing eager `import.meta.glob` wiring and
`resolveWorkshopThumbnail` resolver continue to be used by workshop cards and
shared detail views; no resolver change was required. The retired
`chatgpt_een_(vergiftigd)_geschenk_voor_leraar_en_leerling.jpg` source was moved
to `docs/implementation/source-artifacts/p39-retired/` and is not imported.

Conversion used Sharp 0.35.3, deterministic WebP quality 82/effort 6, EXIF
rotation, and a 1200px max width/height with no upscaling. Aspect ratios are
preserved.
